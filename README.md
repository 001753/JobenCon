# JobenCon — Joben Connect

Platform agregasi data aset keuangan multi-kategori untuk Indonesia & SEA.

## Apa ini?

Joben Connect adalah lapisan infrastruktur data aset keuangan — tempat investor Indonesia bisa melihat seluruh portofolio mereka (kripto, saham IDX, emas, mata uang, reksa dana) dalam satu dashboard, serta developer/fintech bisa mengakses data tersebut via API.
